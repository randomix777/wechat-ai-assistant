微信AI智能助理 · 免安装便携版

首次使用
1. 右键下载的 ZIP 文件，选择“全部解压”。
2. 打开解压后的“微信AI智能助理”文件夹。
3. 双击“启动微信AI智能助理.bat”。
   （也可以直接双击“微信AI智能助理.exe”，效果一样；两个都在，用哪个都行。）

数据随文件夹保存
首次启动后，本文件夹内会出现 data 目录。设置、订单、读取进度和缓存都保存在这里。
迁移或备份时，请退出软件后复制整个“微信AI智能助理”文件夹，并保留 data 目录。
请把软件解压到可写入的位置，例如“文档”或其他普通文件夹；自动更新需要写入程序目录。

旧数据迁移
如果检测到旧版保存在 %LOCALAPPDATA%\wechat-ai-assistant 或 %LOCALAPPDATA%\pyweixin 的数据，
便携版首次启动时会复制到 data 目录，旧目录保留不动。

把软件发给别人（重要）
复制整个文件夹之前，请先退出软件，然后**删掉 data 目录**再发。
data 里是您自己的经营数据：订单、客户名单、读到的聊天记录、运行日志，还有微信数据库密钥。
不删的话，对方一打开就能看到您店里这些数据。
另外两点：
· 登录凭证是 Windows 加密保护的，换电脑本来就解不开，对方需要重新登录自己的账号；
· 对方**登录之前**自动更新可能下不下来（从工具中心下载需要登录），界面顶部会提示原因，
  登录之后会自动恢复。

换电脑
订单、设置和缓存会随文件夹迁移。Windows 加密保护的登录凭证不能跨电脑使用，
在新电脑上需要重新登录微信和产品账号。

如果窗口看起来不像本软件（标题栏或任务栏是 Edge）
有些较旧的 Windows 没有内嵌窗口组件（WebView2）。这种电脑上本软件会自动改用
系统 Edge 打开界面，功能完全一样；同时会在后台自动下载并安装该组件（需要联网），
装好后下次打开就恢复原来的窗口，不需要您做任何事。
如果一直没恢复（例如这台电脑不能上网），请手动安装一次：
https://developer.microsoft.com/microsoft-edge/webview2/

界面打不开、或者提示"127.0.0.1 页面不可用"
双击本文件夹里的「诊断-发给客服.bat」，会打开一个 txt 文件，
把这个文件发给客服即可 —— 里面记录了版本、代理设置、本机端口和最近的运行日志。
（常见原因：电脑上装了代理软件 / 公司网络代理，把本机地址也接管了。）
